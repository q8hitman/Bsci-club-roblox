## 2. نتائج الاختبارات الفعلية داخل Roblox Studio (`v50`)

1. **اختبار المشي الفعلي والكاميرا (`Walkability + Floor Support + 3rd-Person Camera Raycast`)**:
   - تم فحص **11 مساراً حرجاً** بخطوات متصلة (`Jump = 0`) مع فحص ثبات الأرضية تحت القدمين وفحص خط رؤية الكاميرا الخلفية:
     - الممر الأحمر ذهاباً (`z = -34 -> 136`) وإياباً (`z = 136 -> -34`): **`walkOk = true` (`0` عوائق، `0` فراغات أرضية، سلاسة الكاميرا `100%`)**.
     - أبواب الجنوبي الأمامية (`x = -17`, `x = -5`, `x = 17`) والخلفية (`x = -42`, `x = 42`): **`walkOk = true` (`0` عوائق)**.
     - الممشى الخارجي الشرقي (`MAIN`) والغربي (`WEST`) من الجنوبي إلى بوابتي الشمالي: **`walkOk = true` (`0` عوائق)**.
     - مداخل الأجنحة الغربية والشرقية في الطابق الأرضي والأول (`x = ±90`): **`walkOk = true` (`0` عوائق)**.
2. **اختبار وجهات قائمة العوالم الـ15 (`WorldMenu 15 Destinations`)**:
   - تم التحقق من وجود نقاط الهبوط الـ15 كافة وصلابة الأرضية تحت كل نقطة (`groundSolid = true`) وإغلاق القائمة تلقائياً عند الاختيار.
3. **اختبار الكمبيوتر (`1365×768`) والجوال (`iPhone XR 801×413`)**:
   - **`WorldMenu` (`15` بطاقة `5×3`)**: جميع البطاقات الـ15 اجتازت فحص `TextFits` (`15/15`) بدون أي تداخل.

   - **`GameShow` (`memoryRound`) و`LabStation|gram`**: تم التحقق من عمل بنك الأسئلة (`12` تسلسل ذاكرة، `20` صورة، `25` سؤال سرعة) ومنصة صبغة جرام (`4` عينات بكتيرية × `4` خطوات صبغ تفاعلية).
